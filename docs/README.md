# OctoAcme Project Management Docs

This README provides a short summary of OctoAcme's project management processes and links to the full process docs in this repository's docs/ folder.

Summary:
- Initiation: lightweight one-pager to validate the problem and success metrics
- Planning: convert approved initiatives into a prioritized backlog and release plan
- Execution & Tracking: team rhythm, PR workflow, CI, and tracking for day-to-day delivery
- Release & Deployment: pre-release checks, deployment checklist, and rollback playbook
- Retrospective & Continuous Improvement: capture action items and measure impact
- Risk Management & Communication: maintain a risk register and escalation paths
- Roles & Personas: responsibilities for PM, PdM, Devs, QA
